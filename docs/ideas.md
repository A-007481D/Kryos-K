# Ideas Parking Lot

**Rule:** Kryos is a long-term project. Do not start a completely different major project because an interesting subsystem appears. New ideas should be recorded here and deferred unless they directly contribute to the current milestone.

## Future Concepts

- Hypervisor / Virtualization (defer to post-Kryos-K maturity)
- PCI / virtio / network device drivers
- File systems (ext4, custom hierarchical fs with subdirectories)
