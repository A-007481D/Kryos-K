# ADR 0001: Target x86_64

## Context
Kryos is a long-term systems engineering project intended for deep systems learning. We need to select a primary hardware architecture.

## Decision
Target **x86_64** as the primary architecture.

## Alternatives
- ARM64: Excellent modern architecture, but x86_64 has deeper historical layers (real mode -> protected mode -> long mode) which provides more learning value for understanding legacy abstractions and virtualization (VT-x).
- RISC-V: Cleaner design, but x86_64 is ubiquitous on desktop/server hardware and learning its quirks is highly educational.

## Tradeoffs
- x86_64 has significant legacy baggage and complex initialization.
- Requires understanding segmentation, GDT, and 32-bit protected mode even though we ultimately run in 64-bit long mode.

## Consequences
- The kernel will initially boot via a 32-bit entry path before transitioning to 64-bit mode.
- We will need to manage the GDT, IDT, and paging structures specific to x86_64.
